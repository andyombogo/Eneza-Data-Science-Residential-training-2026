# Data dictionary

Every file below is aggregate and non-identifying, generated by the scripts
named in each section (`Makefile` orchestrates them — see README §Reproducibility).
None require restricted KDHS access to read; only to regenerate.

## `data/processed/task2_stunting_summary.json`

Generated by `scripts/regional_analysis.R`.

| Field | Type | Description |
|---|---|---|
| `source`, `source_access` | string | Dataset provenance and access terms |
| `age_band` | string | `12-35 months` — standardized across stunting, immunisation, and SBA (2026-08-04) |
| `methodology` | string | One-paragraph methodology summary (full detail: `docs/methodology.md`) |
| `sample.total_children_all_ages` | int | All children in the cleaned sample |
| `sample.total_clusters` | int | Distinct KDHS survey clusters (`v001`) |
| `sample.stunting_analysis_n_12_35_months` | int | Children in the stunting analysis sample |
| `national.stunting_prevalence_weighted_pct` | float | Survey-weighted national stunting prevalence (%), 12–35 months = 21.7 |
| `subnational` | object | Forest-plot/map image paths (12–35mo) and status note |

## `data/processed/task2_immunisation_summary.json`, `task2_sba_summary.json`

## `data/processed/task2_stunting_by_county.csv`

Generated by `scripts/regional_analysis.R`. One row per county (47 rows).
**6–59 month band** — predates the 2026-08-04 age-band standardization;
kept for the Task 4 v1 ranking's internal consistency. The current
12–35mo county-level view is `Plots/Stunting_forest_plot.png` /
`Plots/Stunting_map.png` (image only, no CSV).

| Column | Type | Description |
|---|---|---|
| `county` | string | County name, title case |
| `prevalence_pct` | float | Survey-weighted stunting prevalence (%) |
| `ci_lower`, `ci_upper` | float | Design-based 95% confidence interval bounds (%) |

## `data/processed/task2_immunisation_by_county.csv`, `task2_sba_by_county.csv`

Same shape as the stunting county CSV above, 12–35 month band. **Not a
rendered R output** — no county-level CSV for these two indicators exists
anywhere in this repo's history, only the recovered forest-plot images
(`Plots/Vaccination_forest_plot.png`, `Plots/Sba_forest_plot.png`). Values
were extracted programmatically from those images (2026-08-05): the point
marker and whisker pixels (`color = "gray30"` in the source `ggplot` code)
were isolated by color, calibrated against the panel's gridlines (known
`y_breaks` from `Project7_task2.qmd`) and cross-checked against the
plots' own annotated national-average reference line (immunisation 50.3%,
SBA 88.8% — matched to within 0.1 point). County order/labels were read
directly off the image; two adjacent, near-tied counties in each plot
(within 0.1 point of each other) were clamped to equal values rather than
guessed apart. Treat these as a **reasonable approximation for ranking and
visualization**, not a re-derived statistic — the real underlying numbers
are whatever `MCH_Kenya_Task2_Task4_Pipeline.qmd` Phase 9 produces once run
against real KDHS data.

## `data/processed/task2_wealth_quintile.csv` *(not yet generated)*

Produced by `scripts/wealth_quintile_analysis.R` once run against an
approved-access copy of the raw KDHS file (see README.md § How to run
locally) — the script is written and ready, gated only on restricted-data
access. Wealth equity is covered in the meantime via the concentration
indices and 3-category breakdown described above. One row per
(indicator × wealth quintile) once generated — 15 rows (3 indicators × 5 quintiles).

| Column | Type | Description |
|---|---|---|
| `indicator` | string | `stunting`, `immunisation`, or `skilled_birth_attendance` |
| `wealth_quintile` | string | `Poorest`, `Poorer`, `Middle`, `Richer`, `Richest` (DHS `v190`) |
| `prevalence_pct` | float | Survey-weighted prevalence (%) |
| `ci_lower`, `ci_upper` | float | Design-based 95% confidence interval bounds (%) |

## `data/processed/task2_wealth_concentration_indices.json`

Erreygers/Wagstaff-style concentration indices (`rineq::ci()`) quantifying
how each indicator distributes across the continuous DHS wealth score — a
complementary method to the discrete quintile table above, answering the
same question a different way. Full provenance (source branch/commit and
recovery method) is in the file's own `provenance` field.

| Field | Type | Description |
|---|---|---|
| `provenance` | object | Source branch/commit/file and how the numbers were recovered |
| `indicators[].indicator` | string | `stunting`, `full_immunisation`, or `skilled_birth_attendance` |
| `indicators[].concentration_index` | float | Negative = concentrated among the poor; positive = concentrated among the wealthy |
| `indicators[].ci_lower`, `.ci_upper` | float | 95% confidence interval bounds |

## `data/processed/task4_priority_counties.csv`

Generated by `scripts/intervention_prioritization.R`. One row per county (47 rows), ranked.

| Column | Type | Description |
|---|---|---|
| `priority_rank` | int | 1 = highest stunting prevalence |
| `county` | string | County name |
| `prevalence_pct`, `ci_lower`, `ci_upper` | float | Passed through from the county stunting CSV |
| `gap_vs_national_pct` | float | `prevalence_pct` − national prevalence, in points |
| `ci_width_pct` | float | `ci_upper` − `ci_lower` — a proxy for estimate precision |
| `priority` | bool | `TRUE` if `prevalence_pct` ≥ national + 1 SD across counties (see `docs/methodology.md`) |

## `Derived_data/task2_stunting_by_county.csv`

Not read by the app (`data/processed/task2_stunting_by_county.csv` is the
canonical file for that). This is a raw R `sf` object written with
`write.csv()` without converting its `geometry` column to WKT first, so
each county's polygon boundary was dumped as literal R list syntax spanning
many raw lines (27,818 lines total) rather than a clean tabular export.
Columns: `county`, `county.y`, `prevalence`, `lb`, `ub`, `geometry`. The
coordinate magnitudes are consistent with Arc 1960 / UTM zone 37S
(EPSG:21037), the CRS `rKenyaCensus::KenyaCounties_SHP` ships in — this is
very likely real county boundary geometry, kept rather than discarded, and
the natural starting point for exporting a proper
`data/external/kenya_counties.geojson` (via `geopandas`/`shapely` to parse
the embedded list syntax, or re-exporting cleanly from R with
`sf::st_write()`) to enable an interactive choropleth in a future pass.
